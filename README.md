# Car evolution — политика конфиденциальности

Разработчик: Яковлев Максим Петрович.
Контакт: kirimaxstudio@yandex.ru. Категория игры: 12+.
Адрес сайта: https://kirimaxstudio.github.io/

Загрузите файлы этого набора в корень репозитория kirimaxstudio.github.io.
index.html должен лежать рядом с README.md, а не внутри папки public.
Для GitHub Pages: Settings → Pages → Deploy from a branch → main → / (root).
После коммита дождитесь публикации в Actions и проверьте сайт в приватном окне.

Текст политики не описывает игровые механики. Он содержит сведения о данных,
целях обработки, сервисах, хранении, правах пользователя и контактах.
Исходник — policy.json. Генерация страницы:
`python build.py --source policy.json --output index.html --require-contact`

В игре остаются только кнопки перехода на сайт, без встроенного текста.
Исходный документ в проекте находится в docs/privacy/policy.json. На сайте не нужны Python или npm.
Исходники игры, APK и ключ подписи сюда не загружать.
После достижения цели обработки удаляйте данные обращений не позднее 30 дней,
если нет другого законного основания хранения (статья 21 152-ФЗ).
Документ не заменяет необходимые согласия и фактические меры защиты данных.
Переход из игры направлен на https://kirimaxstudio.github.io/.
При смене адреса обновите PUBLIC_URL в scripts/privacy_policy.gd.

Дата последнего изменения политики: 8 октября 2026 года.
Номер редакции не используется. При изменении политики обновите поле date
в policy.json и заново сгенерируйте index.html.

Этот набор подготовлен локально; его нужно загрузить в репозиторий сайта.
